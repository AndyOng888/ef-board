    What this demo cannot show

    The real app stamps every punch with the server's time, so a phone with a wrong clock cannot back-date a shift. A page like this has no server, so the time above is your phone's and that protection can only be seen on the real build. Same for the PIN: here it is checked in the browser, which proves nothing — the real one is PBKDF2-hashed on the server with a lockout after five wrong tries.
